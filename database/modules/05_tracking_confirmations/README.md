# Module 5: Tracking Events & Delivery Confirmations

- **Phụ trách**: Nguyễn Thành Nhân (M5)
- **Nhánh Git**: `feat/w1-m5-tracking` | **Commit form**: `w1-01: feat(db): ...`
- **Mục tiêu**: Quản lý dòng sự kiện lịch sử hành trình (Tracking timeline) và xác nhận giao hàng (Proof of Delivery qua OTP/QR).
- **Các thực thể chính cần thiết kế**:
  - `tracking_events` (Bảng sự kiện Append-Only)
  - `delivery_confirmations` (Bằng chứng giao hàng thành công)
- **Yêu cầu kỹ thuật**: Viết bằng T-SQL cho **Microsoft SQL Server**.
