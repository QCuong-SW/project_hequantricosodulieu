# Module 4: Landing Stations & Package Handoffs

- **Phụ trách**: Tấn Tài (M4)
- **Nhánh Git**: `feat/w1-m4-stations` | **Commit form**: `w1-01: feat(db): ...`
- **Mục tiêu**: Quản lý trạm tiếp đất, bãi đáp/dock sạc và biên bản bàn giao kiện hàng (Inbound/Outbound Handoffs).
- **Các thực thể chính cần thiết kế**:
  - `landing_stations` (Danh mục trạm cất/hạ cánh)
  - `station_slots` (Bãi đỗ, dock sạc tại trạm)
  - `package_handoffs` (Biên bản quét mã QR bàn giao kiện hàng)
- **Yêu cầu kỹ thuật**: Viết bằng T-SQL cho **Microsoft SQL Server**.
