# Module 2: Customers, Addresses & Orders Core

- **Phụ trách**: 
  - **Lê Thanh Nhị (M2)**: Hồ sơ khách hàng & Sổ địa chỉ (Nhánh `feat/w1-m2-customers`, Commit `w1-01: feat(db): ...`)
  - **Cường Quang (M3)**: Đơn hàng, Snapshot địa chỉ & Kiện hàng (Nhánh `feat/w1-m3-orders`, Commit `w1-01: feat(db): ...`)
- **Mục tiêu**: Quản lý hồ sơ khách hàng, sổ địa chỉ và quy trình tạo/quản lý đơn hàng cùng kiện hàng.
- **Các thực thể chính cần thiết kế**:
  - `customer_profiles` (Lê Thanh Nhị - M2)
  - `delivery_addresses` (Lê Thanh Nhị - M2)
  - `delivery_orders` (Cường Quang - M3)
  - `order_address_snapshots` (Cường Quang - M3)
  - `packages` (Cường Quang - M3)
- **Yêu cầu kỹ thuật**: Viết bằng T-SQL cho **Microsoft SQL Server 2022**.
