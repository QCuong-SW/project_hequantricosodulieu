# Module 3: Drone Fleet & Flight Scheduling

- **Phụ trách**: Cường Quang (M3)
- **Nhánh Git**: `feat/w1-m3-orders` | **Commit form**: `w1-01: feat(db): ...`
- **Mục tiêu**: Quản lý tài sản đội bay Drone (mô phỏng) và lập lịch bay (Flight Scheduling) cho các đơn hàng đã duyệt.
- **Các thực thể chính cần thiết kế**:
  - `drones` (Đội bay, tải trọng, mức pin)
  - `flight_schedules` (Lịch trình chuyến bay, trạm đi/đến, gán drone)
  - `flight_waypoints` (Các điểm tọa độ mốc mô phỏng đường bay)
- **Yêu cầu kỹ thuật**: Viết bằng T-SQL cho **Microsoft SQL Server**.
